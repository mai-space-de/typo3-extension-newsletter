## Subscriber Management

* Subscriber records — the single source of truth for all newsletter subscribers
* Double opt-in — confirmation email dispatched via `mai_mail`
* Unsubscribe — one-click unsubscribe link handling
* Account integration — `mai_account` opt-in UI writes into this subscriber table when installed

## Campaign Management

* Newsletter campaigns — create and manage newsletter editions in the backend
* Scheduling — schedule newsletter dispatch via TYPO3 Scheduler
